How to install

Up and running in a minute

Choose your platform below. Study Tracker is new and unsigned, so your OS may show a one-time warning — here's exactly how to get past it safely.

Windows

Tested on Windows 10 and 11.

  1. Download the Windows .exe installer from the latest GitHub release. Use .msi mainly for managed or admin deployments.
  2. Run the installer by double-clicking it.
  3. If Microsoft Defender SmartScreen appears, click More info.
  4. Then click Run anyway to continue the installation.
  5. Follow the prompts, then launch Study Tracker from the Start menu.

Why does this happen? SmartScreen warns about apps it hasn't seen before. Study Tracker is new and not yet code-signed, so it gets flagged automatically — this is about reputation, not safety. The source is fully open on GitHub if you'd like to review it.

macOS

Works on supported Mac builds. Choose aarch64.dmg for Apple Silicon Macs and x64.dmg for Intel Macs.

  1. Download the macOS .dmg file from the latest GitHub release.
  2. Open the .dmg and drag Study Tracker into your Applications folder.
  3. If macOS blocks it as being from an unidentified developer, open Applications, right-click the app, and choose Open.
  4. Confirm by clicking Open in the dialog. You only need to do this once.
  5. If macOS says the app is damaged, open Terminal and run xattr -dr com.apple.quarantine "/Applications/Study Tracker.app", then run open "/Applications/Study Tracker.app".

Why does this happen? Study Tracker is currently not Apple-notarized. Gatekeeper may show either an unidentified-developer warning or a damaged-app warning for downloaded unsigned apps. Right-click → Open or removing the quarantine flag tells macOS you trust this copy.

Linux

Available as .deb and .rpm for common package families. Arch, Hyprland-heavy setups, and unsupported distributions should build from source for now.

Download the amd64.deb file Best for Ubuntu, Debian, Linux Mint, Pop!_OS, Zorin, and similar distributions.
Download the x86_64.rpm file Best for Fedora, RHEL-based distributions, and openSUSE.
Build from source Recommended for Arch, Manjaro, EndeavourOS, NixOS, Void, Gentoo, Hyprland-heavy setups, and unknown Linux distributions.
  1. For Ubuntu/Debian or Fedora/openSUSE, download the recommended Linux file from the latest GitHub release.
  2. .deb: install with sudo apt install ./Study.Tracker_*_amd64.deb.
  3. .rpm: install with sudo dnf install ./Study.Tracker-*.x86_64.rpm.
  4. Arch / other: build from source with git clone https://github.com/damcha02/destudydracker.git, cd destudydracker/desktop, npm install, and npm run tauri:build. Start it with ./src-tauri/target/release/app.
  5. To update a source build later, run git pull, npm install, and npm run tauri:build, then start the app again.

Tip: if you are not on ARM, avoid files named aarch64 or arm64. Choose amd64, x86_64, or x64 for normal Intel/AMD PCs. AppImage builds are provided as a fallback, but source builds are recommended on Arch, Hyprland, and unsupported distributions.
